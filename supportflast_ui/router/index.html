Hướng Dẫn Kết Nối Sử Dụng Cho Máy Tính & Termux

Áp dụng cho mọi công cụ lập trình AI trên máy tính như Antigravity, Cursor, Claude Code, Cline, Continue.dev, OpenClaw:

Base URL / Endpoint: https://supportflastdev.io.vn/v1
API Key: sk-9router-xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx (Lấy mã API Key bạn vừa sinh ở bảng phía trên)
Mô hình hỗ trợ: gemini-3.1-pro-high, claude-3-5-sonnet, claude-3-opus, gemini-2.5-pro

Chạy cục Go siêu nhẹ (Pure Go, 0 libSQL, ~8MB, chỉ ngốn ~12MB RAM) ngay trên máy tính của bạn:

  1. Mở thư mục tools/9router-client/ và điền API Key vào tệp config.json:
{
  "web_server_url": "https://supportflastdev.io.vn",
  "api_key": "sk-9router-xxxxxxxxxxxxxxxxxxxxxxxx",
  "local_port": 8080
}

2. Chạy tệp thực thi 9router-client.exe. Trạm Go sẽ tự động nạp Token từ Cloud về RAM và mở cổng http://127.0.0.1:8080/v1.

3. Đổi Base URL trong Antigravity/Cursor về http://127.0.0.1:8080/v1.

Trong môi trường Linux / Android Termux, bạn chỉ cần xuất các biến môi trường sau:

export OPENAI_BASE_URL="https://supportflastdev.io.vn/v1"
export OPENAI_API_KEY="sk-9router-xxxxxxxxxxxxxxxx"
export ANTHROPIC_BASE_URL="https://supportflastdev.io.vn"
export ANTHROPIC_API_KEY="sk-9router-xxxxxxxxxxxxxxxx"
